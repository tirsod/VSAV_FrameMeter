# 既存機能の棚卸し

**提案の前にここを見ること。** 必殺技IDの件のように、
既にあるものを作り直そうとした失敗を防ぐための一覧。
(2026-08-14 作成)

## 車輪の再開発を実際にやりかけた例

`$106`(P2 は `0xFF8906`)= **ゲーム自身の必殺技ID**。
状態バイトから技の発生を判定する仕組みを作ろうとしたが、
`charMoves.lua` に **アドレスもキャラ別の技名表も既にあった**。
トレモの Character Specific モードは、この番地に書き込んで技を出している。
