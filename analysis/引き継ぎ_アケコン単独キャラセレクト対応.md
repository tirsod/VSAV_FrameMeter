## 目的

### キャラセレクト画面でのP1->P2ミラー
```lua
if memory.readbyte(0xFF8009) == 2 then -- キャラセレクト画面
    local p1_sel = memory.readbyte(0xFF8400 + 0x3BD) ~= 0
    local p2_sel = memory.readbyte(0xFF8800 + 0x3BD) ~= 0
    if p1_sel and not p2_sel then
        -- P1決定後30フレーム待ってからミラー開始（ステージ選択の猶予）
        globals._p1_mirror_wait = globals._p1_mirror_wait or 0
        if globals._p1_mirror_wait == 0 then
            globals._p1_mirror_wait = emu.framecount() + 30
        end
        if emu.framecount() >= globals._p1_mirror_wait then
            local _inp = joypad.get()
            _inp["P2 Up"] = _inp["P1 Up"]
            _inp["P2 Down"] = _inp["P1 Down"]
            _inp["P2 Left"] = _inp["P1 Left"]
            _inp["P2 Right"] = _inp["P1 Right"]
            _inp["P2 Weak Punch"] = _inp["P1 Weak Punch"]
            _inp["P2 Medium Punch"] = _inp["P1 Medium Punch"]
            _inp["P2 Strong Punch"] = _inp["P1 Strong Punch"]
            _inp["P2 Weak Kick"] = _inp["P1 Weak Kick"]
            _inp["P2 Medium Kick"] = _inp["P1 Medium Kick"]
            _inp["P2 Strong Kick"] = _inp["P1 Strong Kick"]
            joypad.set(_inp)
        end
    else
        globals._p1_mirror_wait = 0
    end
else
    globals._p1_mirror_wait = 0
end
```
- `P1` が選択済み(`0xFF8400+0x3BD`)かつ `P2` 未選択の間だけ、`P1` のレバー/6ボタンを `P2` へミラー。`Coin/Start` はミラーしない。
- `P1` 決定後に30フレーム(~0.5秒)ウェイトを入れてからミラー開始。`Coin` でステージを決める猶予を確保。ウェイトは `emu.framecount()+30` の `30` で調整可能。
- キャラセレクト画面以外では従来通り。`VsavPrj` 側でもテストで「ウェイトもいいかんじ」と確認済み。

## 使い方
1. P1カーソルでP1キャラ決定 (アケコン)
2. P1 Coinでステージ決定
3. そのまま同じアケコンでP2キャラ決定 (ミラー)
