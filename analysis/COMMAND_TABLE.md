# 全キャラ コマンド表(ROM から抽出)

`0x0BD3FA + キャラID*4` が各キャラのコマンド判定ルーチン。
その中の `lea $XXX / jsr $29XXX / bne` を順に列挙し、
飛び先の `move.b #ID, ($106,A6)` から技IDを読んだもの。
**並び順がそのままコマンドの優先順位**(先にチェックされる方が優先)。
