# 公開ページのソース

アーティファクトとして公開しているページの元ファイル。編集はここで行い、
同じ URL へ再公開する (URL を変えると読み手のブックマークが切れる)。

| ファイル | 内容 | URL |
|---|---|---|
| `changes.html` | 変更点。日本語と英語を1ページで切り替え。版を積み重ねる形式で、古い版も落とさずに残す | https://claude.ai/code/artifact/61ee74de-356c-4223-9419-f76f4ec9c54d |
| `release_notes.html` | **公開を止めた。** 変更点ページと内容が重なるため。ソースは残してあるが更新しない | (旧) https://claude.ai/code/artifact/c2c88a21-4125-49c3-a6cf-737a47c6945b |

公開しているページは変更点ページの1つだけ。リリースノートは
`RELEASE_NOTES.md` / `RELEASE_NOTES.ja.md` として配布物に同梱し、ページは持たない。
版を出すときはこの markdown 2 本と変更点ページの計 3 箇所を更新する。

公開物に個人名・ハンドル・X へのリンクを入れない (2026-09-14 の判断)。

両ページとも日本語と英語を同じファイルに持ち、ボタンで切り替える。URL を分けると
片方だけ更新して食い違うため。日本語以外のブラウザでは英語で開く。

ここに置いてあるのは、以前この2つが一時フォルダにしか無く、消えるとページを
編集する起点が失われる状態だったため。中身そのものはサーバ側にも残る。
